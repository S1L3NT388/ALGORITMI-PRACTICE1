# Робота з масивами

Невеличка програма для лабораторної: генерація масивів та кілька типових задач на обробку масивів.

## Що реалізовано

1. Кількість і сума парних елементів у заданому діапазоні індексів
2. Середнє арифметичне масиву та кількість елементів, більших за середнє
3. Третій масив як попарна сума двох масивів однакової довжини
4. Третій масив як конкатенація двох масивів різної довжини
5. Обмін місцями максимуму та мінімуму в масиві
6. Поділ масиву на додатні та від'ємні елементи
7. Видалення дублікатів максимуму та мінімуму
8. Елементи двох масивів, що потрапляють у діапазон між їхніми середніми

## Запуск

Phyton:
python task.py

Масиви для тестів генеруються випадково, тому результати щоразу трохи відрізняються.
